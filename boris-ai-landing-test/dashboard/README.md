# Boris AI - Dashboard

Dashboard moderno construido con Next.js 14, TypeScript, Tailwind CSS y Recharts.

## Stack Tecnológico

- **Next.js 14** — Framework React con App Router
- **TypeScript** — Tipado estático
- **Tailwind CSS** — Estilos utility-first
- **Recharts** — Gráficos y visualizaciones
- **Lucide React** — Íconos
- **Zustand** — Gestión de estado

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

El servidor se levanta en `http://localhost:3000`.

## Producción

```bash
npm run build
npm start
```

## Estructura del Proyecto

```
src/
├── app/
│   ├── layout.tsx      # Layout principal
│   └── page.tsx        # Dashboard principal
├── components/
│   ├── Sidebar.tsx     # Barra lateral de navegación
│   └── Navbar.tsx      # Barra superior
```

## Features

- Sidebar responsive con navegación colapsable
- Navbar con búsqueda, notificaciones y menú de usuario
- Tarjetas de métricas con tendencias
- Gráfico de área con gradientes
- Tabla de actividad reciente con barras de progreso
