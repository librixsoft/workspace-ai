# Workspace AI

Repositorio de proyectos creados con inteligencia artificial local.
Cada subdirectorio contiene un projecto generado, asistido o prototipado
completamente con modelos de IA ejecutados en entorno local.

## Proyectos

| Carpeta | Descripción |
|---------|-------------|
| `dashboard-ui-game/` | Dashboard interactivo en terminal con Python + Textual |
| `dashboard/` | Dashboard en terminal con Python + Textual, componentes modulares |
| `fedora-retro-landing/` | Landing page estilo Fedora Core Linux retro de los 2000s |
