# Workspaces AI

Todos los proyectos en esta carpeta son demos y experimentos creados con [Boris AI](https://github.com/librixsoft/boris-ai), un agente de desarrollo autónomo que corre localmente.

## Sobre Boris AI

Boris AI es un agente de IA que permite desarrollar software de forma autónoma mediante interacción por chat. Entre sus capacidades destaca el **feature de aprendizaje por repositorios**, que le permite analizar y comprender la estructura de proyectos GitHub existentes para generar código adaptado a patrones y convenciones específicas.

Este repositorio contiene ejemplos prácticos demostrando esa capacidad.

## Requisitos

- [Boris AI](https://github.com/librixsoft/boris-ai) — Agente de IA para correr modelos locales
