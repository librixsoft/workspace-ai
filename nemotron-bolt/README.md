# NEMOTRON BOLT — Landing Page Cyberpunk

Landing page oficial del sistema de lenguaje de gran escala **Nemotron Bolt** de NVIDIA, diseñada con estilo cyberpunk, colores negros, amarillos y grises, estética futurista.

## Características

- Landing completo con HTML5 y CSS3 puro (sin dependencias externas)
- Tema cyberpunk: negro (`#050505`), amarillo metálico (`#ffd700`), grises oscuros
- Efectos visuales: glow, líneas de escaneo animadas, grid de fondo, brillos radiales
- Diseño responsivo con menú hamburguesa para móviles
- Secciones: Hero, Tecnología, Características, CTA y Footer
- Smooth scroll en enlaces internos
- Navigation fija con efecto de borde dorado

## Estética

- **Fondo**: Negro profundo (`#050505` / `#020202`)
- **Acento principal**: Amarillo metálico (`#ffd700`) con efectos glow
- **Texto secundario**: Grises (`#c0c0c0`, `#999`, `#666`)
- **Tipografía**: Segoe UI, Roboto, Helvetica, Arial (sans-serif)
- **Elementos decorativos**: Grid radial, efectos de escaneo, bordes brillantes

## Uso

Simplemente abre `index.html` en cualquier navegador moderno. No requiere build, servidor ni dependencias.

## Secciones

1. **Hero** — Título principal con texto glow y botones de acción
2. **Tecnología** — Grid de 4 cards: Optimizado por NVIDIA, Razonamiento avanzado, Escalabilidad, Seguridad
3. **Características** — Grid de 4 cards: Baja latencia, Contexto extendido, Multilingüe, API completa
4. **CTA** — Llamado a la acción final con botones
5. **Footer** — Copyright y enlaces sociales
