📦 RPM Package Manager


                
RPM Package Manager (RPM) is the default package management system for Fedora Core Linux.

                
  $ rpm -qa | head  # List installed packages
  bash-2.05b-4
  vim-enhanced-6.1-9
  gcc-3.3.1-2
  glibc-2.3.2-95.30
  kernel-2.4.28-1.2115.nptelsg

  $ rpm -qf /usr/bin/gcc  # Find which package owns a file
  gcc-3.3.1-2


                
Popular RPM Commands

                

                    
CommandDescription

                    
                        
`rpm -ivh package.rpm`Install a package with verbose progress

                        
`rpm -Uvh package.rpm`Upgrade an existing package

                        
`rpm -e package`Erase (uninstall) a package

                        
`rpm -qa`List all installed packages

                        
`rpm -qi package`Show info about an installed package

                        
`rpm -qf /path/to/file`Find which package owns a file
