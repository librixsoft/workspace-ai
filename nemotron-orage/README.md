# nemotron-orage

Corporate landing page template built with modern web technologies.

**Created with nemotron-3.5-lightning:30b**

## Overview

A sleek, responsive corporate landing page featuring:
- Clean, modern design with glassmorphism elements
- Full responsiveness from mobile to desktop
- Interactive stats counter animation
- Smooth scroll reveal animations
- Marquee section for branding
- Testimonial/partner logos section
- Functional footer with navigation links

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Google Fonts (Inter)
- Vanilla JavaScript for animations and interactions

## Customization

- Update color variables in `:root` CSS block
- Replace images and content as needed
- Modify sections to fit your brand identity
