# tambo-tui dashboard-demo

Proyecto creado con **Boris-AI Agent** — agente autónomo de desarrollo.

## Descripción

Demostración de dashboard terminal usando la librería tambo-tui.

## Cómo ejecutar

```bash
./run.sh
```

O manualmente:

```bash
mvn clean compile package
java -jar target/dashboard-demo-1.0.0.jar
```

## Requisitos

- Java 21+
- Maven 3.8+
