# Lanterna Dashboard

Terminal-based dashboard application built with Lanterna library.

## Features

- Real-time KPI metrics with sparkline visualizations
- Bar charts, line charts, and donut charts
- Data tables with styled rows
- Resource monitoring with color-coded progress bars
- System status indicators
- Activity feed and notifications
- Quick actions panel
- Responsive layout with sidebar navigation

## Build

```bash
mvn clean package
```

## Run

```bash
java -jar target/lanterna-dashboard-1.0-SNAPSHOT.jar
```
