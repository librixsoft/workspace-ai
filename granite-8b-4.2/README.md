# Granite 8B 4.2 – Modelo de lenguaje empresarial

Granite 8B 4.2 es una arquitectura de lenguaje de gran tamaño optimizada para entornos empresariales. Combina precisión, rendimiento y interfaz corporativa con un diseño limpio y profesional.

## Diseño corporativo

- **Fondo:** Blanco (`#ffffff`) – limpio y profesional
- **Colores principales:** Naranja corporativo (`#ff6b35`) para botones, títulos y llamadas a la acción; Naranja suave/acento (`#d95e1b`) para detalles de énfasis
- **Tipografía:** Segoe UI / sans-serif web, fácil de leer, limpio y profesional
- **Paleta secundaria:** Grises oscuro (`#333333`) para texto principal y gris claro (`#777777`) para textos secundarios

Este diseño se mantiene coherente en todas las secciones de la landing page y refleja una identidad corporativa moderna y confiable.

## Landing page (index.html)

La página incluye las siguientes secciones corporativas completas:

1. **Hero** – Título principal `Granite 8B 4.2` con texto descriptivo y botón `Descubrir más`, con fondo blanco y degradado naranja claro en la parte inferior para indicar identidad visual.

2. **Sobre nosotros** – Descripción empresarial concisa sobre qué es Granite 8B 4.2 y su enfoque corporativo.

3. **Características principales** – Tres tarjetas (`card`) usando diseño grid con iconos implícitos en el texto, mostrando: Precisión empresarial, Rendimiento optimizado, Seguridad integrada.

4. **Casos de uso** – Lista estructurada de use cases empresariales relevantes (consultas internas, generación de documentos ejecutivos, chatbots empresariales, etc.).

5. **Testimonios** – Tres testimonios realistas con citas y nombres ficticios del equipo (Ana Martínez, Luis Gómez, Carmen Torres), usando cuadros con borde naranja.

6. **Equipo** – Breve descripción del equipo interno, dividido en tres tarjetas (Ingeniería, Seguridad, Soporte Empresarial).

7. **Contacto** – Información de contacto básica y botón `Contáctanos`.

8. **Footer** – Información legal y de marca con color gris claro sobre fondo blanco.

Todo el CSS está en línea para simplicidad; no requiere build. La página es completamente funcional y responsiva.

## Características del modelo

- **Precisión empresarial:** Alta calidad en generación de texto, respuestas a preguntas y generación creativa, alineado con estándares corporativos.
- **Rendimiento optimizado:** Procesamiento rápido incluso con textos largos y consultas complejas.
- **Seguridad integrada:** Medidas de privacidad y seguridad desde el diseño, adecuado para entornos empresariales.
- **Interfaz corporativa:** Usamos blanco como fondo, naranja (#ff6b35) como color principal para botones y llamadas a la acción, y naranja suave (#d95e1b) como acento para detalles.

## Uso

Simplemente abre `index.html` en cualquier navegador moderno (Chrome, Firefox, Safari, Edge). No se requiere servidor ni compilación.

## Colores corporativos oficiales

- Fondo principal: `#ffffff` (blanco)
- Color naranja principal: `#ff6b35`
- Color naranja suave/acento: `#d95e1b`
- Texto principal: `#333333` (gris oscuro)
- Texto secundario: `#777777` (gris claro)

Estos colores se usan consistentemente en botones, títulos y elementos de énfasis para mantener una identidad visual corporativa coherente.
